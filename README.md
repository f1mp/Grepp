# Grepp

En mobilvänlig gitarrapp för att utforska ackord, lära sig grepp och hitta skalor som passar. Grepp kan också använda enhetens mikrofon för att föreslå vilket ackord som spelas. Ljudanalysen sker lokalt i webbläsaren och inget ljud sparas.

## Funktioner

- Tydliga greppdiagram för vanliga öppna ackord
- 216 kombinationer av grundtoner och ackordtyper
- Ackordtoner och rekommenderade skalor
- Realtidsanalys via mobilens eller datorns mikrofon
- Responsiv design för mobil, surfplatta och dator

## Kör lokalt

Du behöver Node.js 22 eller senare.

```bash
npm install
npm run dev
```

Öppna sedan `http://localhost:3000`.
